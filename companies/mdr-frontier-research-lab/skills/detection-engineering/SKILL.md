---
name: detection-engineering
description: Translate threat scenarios into MDR telemetry coverage, detection hypotheses, and triage pivots.
---

Use this skill when a case needs monitoring, hunting, alerting, or investigation guidance.

Process:

1. Map scenarios to telemetry sources.
2. Define expected signals and false-positive risks.
3. Propose detection hypotheses and triage pivots.
4. Include example query logic only when it is defensive and adaptable.
5. State validation methods and residual blind spots.

Output a detection coverage matrix plus prioritized detection ideas and validation steps.
